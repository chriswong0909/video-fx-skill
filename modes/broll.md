# 模式 B：B-roll 動態插片
用喺：已剪好嘅真人片，要喺講到某啲字嗰刻插動態圖像（行內「motion B-roll」做法）。

## 問卷加問
- **密度**：輕（每 30 秒 1–2 段）｜中（3 段）｜重（4–5 段）。建議先做重，用戶再刪。
- **版面**：講者有冇縮埋一邊（有就用透明板放空位）。

## 每段插片要定
| 欄 | 選項 |
|---|---|
| 觸發字 | 由 chars.json 攞時間，畫面喺講嗰個字嗰格出 |
| 版面 | `cutaway` 全屏蓋住講者｜`panel` 講者縮邊，透明板放另一邊｜`overlay` 疊喺講者旁邊（避面） |
| 長度 | 1.5–4 秒 |
| 主角物件 | 見下 |

## 核心技巧：一件物件連續變形
全段（甚至全片）用**一件主角物件**，由一個形狀變去下一個（圓 → 卡 → 圖表 → logo），唔好每段換一套新元素。
- 變形用系統卡嘅 0.6 秒 `power2.inOut`；內容喺短暫模糊後面換。
- 新元素「拖入」畫面時由主角物件分裂出嚟，唔好憑空出現。
- 同一片嘅插片共用色、緩動、陰影（動態系統卡）。

## 交付
- 每段插片獨立 composition（`broll/<n>/index.html`）+ 合成版。
- 出一頁 HTML 預覽（每段一個 `<video>` + 觸發字 + 版面），用 Artifact 發佈俾用戶揀邊段留。
