# 模式 D：產品／品牌宣傳片
用喺：產品上市、SaaS／App 宣傳、活動宣傳、實物產品廣告。

1. **品牌研究**：用戶俾網址 → 讀網站：定位、核心好處、對象、品牌色、字體、真實 UI 截圖（唔好自己作 UI）。寫入 `brands/<brand>.md`。
2. **零件清單（spec list）**：由產品 UI 拆出 5–8 款零件（按鈕、卡、剔號、loader、圖表、logo lockup），全部用品牌 tokens，寫入動態系統卡。
3. **主角元素**：一個容器由頭到尾唔斷，每個狀態係同一個元素變大細、圓角、填色，內容喺模糊後面換。
4. **節拍**：先寫 state list on beat grid（每拍：時間｜主角狀態｜出咩零件｜聲），用戶批咗先寫 code。要跟拍就出 `beats.json`（BPM、拍點、重拍），動作對拍。
5. **實物產品**：描述材質、光點打落表面、郁法；慢／柔（護膚）定快／爆（飲品）寫入系統卡 tokens。生成鏡頭先出靜圖批核。
6. 收尾 logo lockup；唔做假評價、假數據、假認證。
