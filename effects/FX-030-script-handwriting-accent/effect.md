## 效果
大粗無襯線主字（Starting）旁邊／下面疊一個手寫草書字（from the Scratch），草書似用筆寫出嚟（由左至右 reveal）；變奏：霓虹發光草書（like 2025）。

## 幾時用

個人品牌、生活、勵志內容，加入「人味」。

## 參數同節奏


- 草書字體：英文用 Google Fonts 例如 "Mrs Saint Delafield"／"Caveat"；中文可用「LXGW WenKai」或手寫風字體
- reveal：clip-path inset(0 100% 0 0) → inset(0 0 0 0)，0.6s power1.inOut
- 霓虹版：color #bfefff，text-shadow 0 0 8px #5ad0ff, 0 0 24px #1fa2ff


## 已知限制

中文手寫字體選擇少，要揀字形清楚嘅。
