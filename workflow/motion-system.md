# 動態系統卡（motion system）：風格統一但效果多變

**問題：** 以前每一拍由效果庫揀一個效果，每個效果自帶緩動、顏色、入場方式 → 每下都「新」，擺埋一齊就散。
**行內做法：** 先定一套動態系統，所有畫面元素都由佢生出嚟；變化只嚟自**內容、大細、位置、構圖**，唔係嚟自「又一種新效果」。

## 流程位置
```
intake → 剪停頓 → (參考片 → style-guide) → treatment → ★ 動態系統卡 ★ → 分鏡 + 節拍表 → 關鍵格靜圖批核 → build
```
系統卡同 treatment 一齊俾用戶批。品牌已有系統卡（`brands/<brand>/motion-system.md`）就直接沿用，只列出今次有冇改。

## 系統卡六部分（全部要寫到可以直接變 code）
1. **主角元素（hero）**：全片一個貫穿元素，有 2–3 個狀態（例如 標題條 ↔ 關鍵詞膠囊）。連續兩次使用相隔 < 1 秒 → **變形過去（morph）**，唔好退場再入場；相隔 ≥ 1 秒就退場，唔好為咗變形令舊字喺講者身上停留；文字喺短暫模糊後面換。
2. **零件清單（≤ 5 款）**：每款寫形狀、字級、顏色、放邊。所有零件用同一套圓角、陰影、字體。效果庫嘅效果要先「換皮」成其中一款零件先用得。
3. **Tokens**：
   - 色：主色 1 + 警示 1 + 正面 1 + 中性色；品牌固定色（名牌、字幕、logo）另列，唔計入。
   - 緩動 ≤ 3：入場（例如 `power3.out`）、出場（`power2.in`）、移動／變形（`power2.inOut`）；`none` 只准用喺 ≥ 1 秒嘅慢推。
   - 時長 3 級：快 0.2｜標準 0.35｜變形 0.6。
4. **入場文法（≤ 4 種）**：例如「由最近畫面邊伸出」「向上浮入」「變形」「劃線（只限警示）」。
5. **出場文法 + handoff**：出場方向同入場相反；上一個元素出場嗰下就係下一個入場（同一時間點、同一方向）。
6. **聲效語言**：每種入場配固定一個聲效（見 `lessons/sound-mixing.md`），唔好逐個效果揀聲。

## 例外
品牌指定嘅開場（例如 Healthy Days 戲劇化開場）、名牌、字幕可以喺 `exempt` 列明唔受限，但只限嗰幾個元素。

## 機讀版（QA 用）
每張系統卡都要有 `motion-system.json`，`scripts/qa-motion.cjs` 會對住佢檢查實際時間軸：
```json
{
  "name": "healthy-days",
  "hero": "#hero",
  "palette": {"#2f68a8": "主色", "#e8452c": "警示", "#1f9d6b": "正面", "#ffffff": "白", "#0b2a3a": "字", "#f4f7fa": "卡底"},
  "palette_fixed": ["#0b6f99", "#13b8d0", "#1a80d0"],
  "easing": ["power3.out", "power2.in", "power2.inOut"],
  "durations": [0.2, 0.35, 0.6],
  "entries": ["slide-edge", "rise", "morph", "draw"],
  "components": ["hero", "chip", "row", "nametag", "hook", "caption"],
  "exempt": ["#camInner", "#hook", "#ecgHook", "#flash", "#vig", "#tag"]
}
```
- `components`：manifest 嘅每個 kind 要對應一款零件（喺 manifest 加 `comp`）。
- 超出任何一項 → QA ✗，唔准渲染。

## 點樣做到「多變」
同一套零件，變化嚟自：
- **內容**：字、圖、數字唔同。
- **構圖**：同一零件放唔同位置、唔同大細（狀態）。
- **節奏**：逐個出、一齊出、越出越快。
- **變形**：主角元素由標題條變成關鍵詞膠囊，再變返標題條，觀眾見到嘅係「同一樣嘢喺度郁」。
