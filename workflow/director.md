# 導演模式：treatment 關卡 + 部門清單

**為咩要有：** 以前係逐個效果揀，揀完先發現漏咗聲效、漏咗調色、成條片風格唔一致。
導演模式喺揀任何效果**之前**，先用一頁 treatment 定好「呢條片講乜、點樣講、用咩風格」，
之後每個部門（剪接、字幕、動態、素材、調色、聲效、QA）都照住呢頁做，唔可以自己另起爐灶。

## 流程位置
```
開工問卷 → 轉錄 + 剪停頓（tools/cut.py）→ ★ treatment（揀風格包）★ → ★ 節拍表 ★ → ★ 卡片 9:16 預覽 ★ → build → QA + 自評分 → ★ 草稿 ★ → 正式版
```
treatment 冇確認，唔准出分鏡、唔准揀效果。

## Treatment（一頁，用表格俾用戶睇）

| 欄 | 寫乜 | 例子（膝痛醫生片） |
|---|---|---|
| 核心一句（thesis） | 觀眾睇完要記住嘅一句說話，≤ 20 字 | 膝頭痛唔一定要換骹，肌肉先係關鍵 |
| 觀眾問題（open loop） | 開頭拋出、結尾先答嘅問題 | 「成日膝頭痛，係咪退化？」 |
| Hook（三個選項） | 頭 3 秒講乜＋畫面點做，俾用戶揀一個 | A 反問句大字／B 數字衝擊（「七成人…」）／C 痛點動作特寫 |
| 結構 | hook → 2–4 個 body beat → payoff，每段寫原片時間 | hook 0–3s｜beat1 誤解 3–12s｜beat2 原因 12–25s｜beat3 做法 25–40s｜payoff 40–45s |
| 視覺比喻 | 全片一個主比喻，所有圖卡圍住佢 | 膝頭 = 避震器（肌肉係彈弓） |
| 色彩意思（≤ 3 色） | 每隻色代表乜，全片唔准亂用 | 主色＝醫生講法；警示紅＝錯誤觀念；綠＝做法 |
| 風格包 | `styles/kallaway` 或 `styles/vox-explainer`（DESIGN.md 一套過）+ 品牌覆蓋 | kallaway + Healthy Days |
| 字幕 | 款式 + 密度 + 寫法 | FX-051 方框字幕，只出重點字，口語 |
| 調色 | GR-xxx + 原因 | GR-001 專業專訪（按醫療健康推薦） |
| 聲效 | 密度（少／中／多）+ 聲效家族；**冇 BGM**；人聲輕度清理 | 少：只喺 beat 轉換同數字出現位 |
| 節奏 | 剪停頓門檻（fast 0.4／medium 0.55／slow 0.8）+ 口頭禪處理 | medium，呃／嗯全剪，其實／即係逐個睇 |
| 講者佔比 | 講者見到嘅時間比例 + 全屏圖卡上限 | 講者 ≥ 70%，全屏卡 ≤ 3 張 |

**關卡：** 出完 treatment 表，問用戶「確認 treatment？（揀 hook A/B/C）」，停低等答覆。

## Beat 角色（分鏡每一鏡都要標）
每鏡加 `beat`：`hook`｜`setup`｜`tension`｜`proof`｜`turn`｜`payoff`。
- 效果強度跟 beat：hook 同 turn 可以用大效果；setup／proof 以講者 + 字幕為主；payoff 收返乾淨。
- 同一 beat 入面唔轉風格；轉 beat 先換機位 + 轉場（用預設嘅轉場組）。
- 每 2.2 秒冇新視覺資訊，要寫 `holdReason`（例如「講者情緒位，唔好打斷」）。

## 部門清單（出分鏡前逐個剔）

### 1. 故事同節奏
- [ ] 頭 3 秒有 hook（字 + 畫面），唔係「大家好我係…」
- [ ] 觀眾問題喺頭 5 秒拋出，payoff 真係答到
- [ ] 每個 body beat 有一句重點字
- [ ] 剪完停頓後長度符合平台（Reels 建議 ≤ 60s）
- [ ] 接位（edl.json `joins`）每個都有處理：轉機位或者 FX-040

### 2. 字幕
- [ ] 全片只用一款字幕（預設指定），字級 ≥ 72px
- [ ] 特效字唔放字幕區、唔同字幕差唔多大（≥ 130px 或 ≤ 64px），見 `lessons/layout-safety.md` 第 7 節
- [ ] 每個特效字元素 ≤ 8 字；全屏卡標題只放關鍵詞，唔放旁白原句
- [ ] 名牌位置、時間跟品牌檔（brands/）
- [ ] 醫療限定詞（唔、可能、建議、除非…）完整保留，冇被剪、冇被縮短
- [ ] 字幕喺安全區（x 90–930、y 200–1600）同面部禁區以外

### 3. 動態（風格包，`workflow/style-packs.md`）
- [ ] 全片只用一個風格包（Healthy Days 預設 kallaway），冇混入效果庫效果
- [ ] 每張卡答到一條問題（記住乜／結構／數字／節奏），冇為咗郁而郁（`workflow/beats.md`）
- [ ] tier1 全屏卡 2–4 張；tier2 卡跟住話題，唔係每句閃
- [ ] 用到嘅卡全部有已驗證 9:16 版；新改嘅卡已經出預覽俾用戶批
- [ ] 同一 purpose 用同一張卡；卡內 cues 對住講嘅字

### 4. 素材
- [ ] 所有圖卡用同一個視覺比喻
- [ ] AI 生成素材已報價 + 確認（生成圖唔使醫生審核）

### 5. 調色同一致性
- [ ] 字體 ≤ 2、色 ≤ 4、每格最多 1 個強調色
- [ ] 色彩意思冇用錯（警示色唔可以用喺正面內容）
- [ ] B-roll 同講者片調色一致（或者刻意唔同並寫明原因）
- [ ] 跑 `node scripts/check-style.mjs <composition.html> presets/SP-xxx`（第 4 步完成後可用）

### 6. 聲效
- [ ] 冇背景音樂
- [ ] 聲效只用預設家族；密度符合 treatment
- [ ] 人聲輕度清理（高通 80Hz + 輕 de-noise + loudnorm -16 LUFS），唔好改變聲線

### 7. QA（出片前關卡，唔過唔准渲染／交片）
- [ ] `tools/qa.py check`：字對聲、字幕逐字、特效字 ≤8 字、頂部大字 ≤4、冇 immediateRender:false
- [ ] 自評分 `critique.json` 全部 ≥ 7（`workflow/critique.md`）
- [ ] `scripts/qa-stills.cjs`：每個畫面字全尺寸截圖，逐張睇（顏色撞唔撞、交叉位、名牌同參考圖並排）；安全區、logo、置中、結束後冇殘留全過
- [ ] 渲染後再喺成品抽每個效果出現時同結束後 0.4 秒嘅格，確認同瀏覽器一致
- [ ] `lessons/preflight-checklist.md` 15 項全過
- [ ] 草稿 contact sheet 冇黑格、殘字、字幕遮面
- [ ] 正式版長度、幀數、比例、音軌核對

## 醫療內容紅線
- 唔可以剪走或者改寫限定詞令意思變絕對（「可能有幫助」→「有幫助」）。
- 數字、藥名、劑量字幕要逐字對返原話。
