# 參考片 → 風格指南（只拎文法，唔拎內容）

**點解要咁做：** 以前睇完 contact sheet 就直接揀效果，結果係「感覺似」而唔係「規則似」。
行內做法：參考片先拆成一份**風格指南**（可重用嘅規則）+ 一張 **shot list**（套用喺我哋內容），之後所有效果照規則砌。

## 步驟
1. **抽格同數據**（用戶提供檔案；YouTube 片唔好自己下載，請用戶俾檔）
   ```
   bash scripts/analyze-ref.sh ref.mp4 refs/<slug>/work          # 每 0.5 秒一格 sheet、剪接點、靜音
   python3 tools/ref_style.py refs/<slug>/work ref.mp4 refs/<slug>  # 自動量度 → style-guide.md 骨架
   ```
   `ref_style.py` 會自動填：鏡頭長度（平均／中位／最短／最長）、每 10 秒剪幾多下、主色板（6 色 hex + 佔比）、亮度／飽和度、有冇顆粒（高頻噪聲）。
   可以輔助用 Higgsfield `video_analysis_create` 拎一份鏡頭描述（要 credits，先問）。
2. **睇格填文法**（只 stage `sheet.jpg` 去雲端 Read；動作睇唔清先抽 2–3 格大圖）。`style-guide.md` 每欄都要填：

   | 欄 | 要寫到幾具體 |
   |---|---|
   | 主角元素（hero） | 全片有冇一個元素貫穿（例如一個圓角框一直變形）；冇就寫「冇」 |
   | 色板同色彩意思 | hex + 每隻色用喺乜（標題／強調／警示） |
   | 字體 | 粗細、大細比例、中英混排、描邊／陰影 |
   | 字點入 | 方向、距離、時長、緩動感覺（彈／順滑／硬切），逐字定成句 |
   | 字點出 | 同上；有冇 handoff（上一個出場＝下一個入場） |
   | 轉場 | 類型 ≤ 3 種，各用喺邊種位 |
   | 鏡頭運動 | 推拉／平移／震；幅度 |
   | 節奏 | 平均鏡頭長度、重拍位落乜 |
   | 質感 | 顆粒、紙紋、光暈、陰影深淺 |
   | 版面 | 字放邊、留白、網格 |
   | 聲效語言 | 幾時落聲（唔好抽聲效本身） |
   | 唔好抄 | logo、角色、相片、原句、音樂 |

3. **轉成我哋嘅動態系統卡**：style-guide 係「參考片點做」，`motion-system.md`（見 `workflow/motion-system.md`）係「我哋條片點做」。兩者對唔上嘅（例如英文字距、品牌色）喺系統卡寫明點改。
4. **Shot list**：用我哋內容逐拍寫（時間｜講緊｜主角元素狀態｜畫面｜參考片邊一格做依據）。之後直接變成節拍表（`workflow/stills-gate.md`）。
5. 存檔：`refs/<slug>/style-guide.md` + `sheet-small.jpg`（闊 ≤ 1200px），唔放原片。同一品牌用開嘅參考 → 寫入 `brands/<brand>/motion-system.md`，下次直接沿用。

## 原則
- **文法唔係內容**：拎佢點郁、點排、點轉；唔拎佢講乜、畫乜。
- 參考片用真相而我哋冇 → 寫明用咩代替（Canva 生成／原片截圖），效果會點變。
- 非中文參考：有字嘅手法跟 `lessons/cjk-adaptation.md` 檢查，中文試一格縮到 360px 睇得清先算。
- 參考片收集：`refs/` 入面每個 style-guide 都係將來可以揀嘅「風格」，唔使每次重拆。
