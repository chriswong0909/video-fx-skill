# 開工問卷（強制，唔可以跳過）

**任何分析、轉錄、分鏡之前，一定要問晒三輪。** 即使使用者訊息已經講咗部分，都要喺問題入面預選／確認。
只有使用者明確講「唔使問」「照你意思」先可以跳過，而且要喺需求摘要度列明用咗咩預設。
AskUserQuestion 唔可用時，用文字列出問題，然後停低等回覆。

## 第一輪：基本
| 題目 | 選項 |
|------|------|
| 參考片 | 有（請提供）／冇，由你建議／有但只參考部分 |
| 平台同長度 | Reels/Shorts 9:16 保持原長度／9:16 可剪短／16:9 YouTube／1:1 |
| 品牌色同字體 | 用 brands/ 現有品牌檔（列出名）／我提供色碼／跟參考片／冇，由你建議 |
| 字幕寫法 | 廣東話口語／書面語／英文／中英雙語 |

## 第二輪：風格同節奏
| 題目 | 選項 |
|------|------|
| 節奏 | 快（1–2 秒一剪，推鏡多）／中（2–4 秒）／慢（保留講者，少剪） |
| 情緒 | 專業醫療／溫暖生活／活潑年輕／高級編輯感（決定風格預設 SP-001～005，見 presets/README.md） |
| 字幕密度 | 逐詞跳字（FX-018）／兩層重點字（FX-017）／只出重點字 |
| 聲效 | 聲效密度：少（只重點位）／中／多（由 sounds/ 聲效庫揀）。唔做背景音樂（上 IG 先加） |

## 第三輪：素材同限制
| 題目 | 選項 |
|------|------|
| AI 生成素材 | 唔用／少量（例如 ≤ 20 credits）／可以放手用，出分鏡時報價 |
| 講者出鏡 | 全程見到講者／可以用全屏過場蓋住講者 |
| 剪停頓同口頭禪 | 按節奏剪（建議）／只剪呃嗯同頭尾／唔剪，保留原樣 |
| 觀眾要記住乜 | 自由填寫一句（例如「膝痛唔一定要換骹」）；唔填就由 treatment 建議 |
| 特別要求或禁忌 | 自由填寫（例如唔要某顏色、要 logo、醫生名同職銜） |

## 問完之後
輸出「需求摘要」（一個表：項目｜答案），問一次「確認需求？」先進入轉錄同剪停頓（`lessons/cutting-cantonese.md`），
然後出 **treatment**（`workflow/director.md`），確認 treatment 先出分鏡。Hook 一定有（由 treatment 出三個選項），唔做結尾 CTA、唔做背景音樂。
節奏答案直接決定鏡頭長度（三機位 W/M/C）同 cutaway 數量；情緒答案用嚟篩 registry 嘅 mood。

## 調色（唔使另外問）
- 按影片類型／情緒自動推薦：`python3 tools/grade.py recommend <影片類型> [情緒]`（例如醫療健康 → GR-001 專業專訪）。
- 需求摘要一定寫「調色：GR-xxx（按 X 推薦）」；使用者喺特別要求講過顏色（跟參考片、保持原色、指定風格）就跟佢。
- 分鏡關卡附調色對比圖（原片｜推薦｜兩個備選）。詳見 `lessons/color-grading.md`。

## 風格包（2026-10-01 起，第二輪必問）
- 選項：Kallaway（現代暗底發光玻璃，Healthy Days 預設）／Vox 解說（紙感、襯線、手繪圈註；品牌禁襯線就唔用）。
- 品牌檔有預設就預選，寫明「你嘅品牌預設 Kallaway，確認？」。
- 需求摘要表一定有「風格包」一行。
