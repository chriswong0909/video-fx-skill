# Healthy Days 動態系統卡（v1，2026-09-30）
機讀版：`motion-system.json`（QA 用）。規則出處：`workflow/motion-system.md`。

## 1. 主角元素：藍膠囊（#hero）
藍 #2f68a8、白色十字 + 白字 Noto Sans TC 900。一個元素、兩個狀態：

| 狀態 | 位置 | 字級 | 形狀 | 用喺 |
|---|---|---|---|---|
| T 標題條 | 由左邊伸出，y 228（logo 左邊，右邊 ≤ 720） | 64px | 右邊圓 | 全屏圖片／資訊卡標題 |
| K 關鍵詞 | 置中 540，y 392（logo 下面） | 104px | 全圓膠囊 | 頂部關鍵詞（全片 ≤ 4） |

- 相隔 < 1 秒嘅兩次使用 → **變形**（≥ 1 秒就退場再入，唔好令舊字停留）（0.6 秒，位置、大細、圓角一齊變；字喺模糊後面換）。
- 換圖但仍係 T 狀態 → 只換字（膠囊闊度 0.35 秒跟住變）。
- 填色：預設藍；正面訊息（例如「盡早檢查」）變綠 #1f9d6b；錯誤觀念用紅色劃線，膠囊保持藍。

## 2. 零件（5 款）
| 零件 | 樣 | 入場 | 出場 |
|---|---|---|---|
| hero 藍膠囊 | 上面 | 由左邊伸出／變形 | 縮返左邊 |
| chip 白膠囊 | 白底、藍字 64px、全圓、細陰影 | 由最近邊滑入 | 淡出 |
| row 卡片行 | 全屏卡內：圓相（藍框）+ 字 88px；或白色圓角條 | 向上浮入 | 跟卡一齊收 |
| nametag 名牌 | 品牌樣板（例外） | 向上浮入 | 淡出 |
| caption 字幕 | FX-051 方框（例外） | 硬切 | 硬切 |
開場 hook 係 Healthy Days 例外（戲劇化開場），唔受入場文法限制。

## 3. Tokens
- 色：主色 #2f68a8｜警示 #e8452c｜正面 #1f9d6b｜字 #0b2a3a｜白｜卡底 #f4f7fa、淺藍 #d6e3f2。
  品牌固定（唔計）：字幕底 #186baa、名牌 teal #13b8d0 / 藍 #1a80d0、logo。
- 緩動：入場 `power3.out`｜出場 `power2.in`｜變形／鏡頭 `power2.inOut`｜慢推 `none`（≥ 1 秒）。
- 時長：0.2｜0.35｜0.6。

## 4. 入場文法
由最近畫面邊伸出（hero、chip）｜向上浮入 30px（row、名牌、第一次出現嘅 K 狀態）｜變形（hero 狀態轉換）｜劃線（只限錯誤觀念嘅紅交叉）。

## 5. 出場 + handoff
出場方向同入場相反：hero 縮返左邊、chip 淡出、K 狀態向上淡出。hero 相隔 < 1 秒唔退場，直接變形。

## 6. 聲效語言
| 動作 | 聲效 |
|---|---|
| hero 伸出／變形 | SFX-014 卡片滑入 |
| chip／row 出現 | SFX-005 柔和 pop |
| 紅交叉 | SFX-010 錯誤警示 |
| 綠色正面 | SFX-009 上升提示音 |
| 名牌 | SFX-005 |
| 開場（例外） | SFX-015 心跳 + SFX-011 重擊 |
