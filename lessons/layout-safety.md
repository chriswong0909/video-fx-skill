# 版面安全：最細字、面部禁區、唔加未要求嘅元素

來源：doctor-stairs-breath（2026-09-29）用戶回饋：字太細、字幕太碎、加咗冇要求嘅時間條、特效字遮住面部。

## 1. 最細字準則（1080×1920 畫布）
1080px 喺手機約顯示成 390pt，即縮到約 0.36 倍。

| 用途 | 最細 | 手機約 |
|---|---|---|
| 特效大字 | 150px | 54pt |
| 特效細字、前導字 | 72px | 26pt |
| 標籤、膠囊、UI 字 | 64px | 23pt |
| 基本字幕（FX-039） | 80px | 29pt |
| 註腳（免責等） | 52px，每條片最多一處 | 19pt |

- 大字 ÷ 細字 ≤ 2.5，否則細字會被壓到更細。
- 16:9 或 1:1 畫布按短邊比例換算（最細字 × 短邊 ÷ 1080）。
- snippet 數值低過準則，一律以準則為準。

## 2. 字幕規則
- 全片只得一種字幕：FX-039（白字 + 黑光暈，80px，按意群 6–12 字，單行）。
- 字幕入面唔准換色、反白、加底色。要強調就用特效字。
- 有特效字顯示緊嗰句內容，嗰句唔出字幕，唔好疊。
- 分鏡每鏡要標明「字幕：FX-039」或「字幕：由特效字取代」。

## 3. 面部禁區
snippet 嘅 top／left 係喺另一條片學返嚟，換咗講者、構圖或推鏡倍數就會唔啱。
1. 每個鏡頭抽中間一格做面部偵測（OpenCV Haar 或 mediapipe），得到面部方框。
2. 按該鏡推鏡倍數同 transform-origin 換算成畫面座標：
   `x' = ox + (x - ox) × s`，`y' = oy + (y - oy) × s + ty`
3. 禁區 = 面部方框四邊各加 10%（頭頂再加 15% 留頭髮）。
4. 特效字只可以放喺頭頂空位（placement: headroom）或胸口以下（lower）；頭頂位唔夠高就減行數、移落胸口，或者降低推鏡倍數。
5. 渲染草稿前，逐鏡計所有文字元素嘅 getBoundingClientRect()，同禁區有重疊就停，唔准出片。

```python
import cv2
c = cv2.CascadeClassifier(cv2.data.haarcascades + 'haarcascade_frontalface_default.xml')
img = cv2.imread('frame.jpg'); g = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
faces = c.detectMultiScale(g, 1.1, 5, minSize=(120, 120))  # [(x,y,w,h), ...]
```

## 4. 平台介面安全區（9:16，約數）
上 200px、下 380px、右 140px 會被 TikTok／Reels／Shorts 介面遮住；重要字唔好放入去。

## 5. 唔加未要求嘅元素
效果庫冇、用戶又冇要求嘅元素（進度條、水印、額外圖示等）預設唔加。
想加就喺分鏡確認問題入面逐項列出，用戶講「要」先加；唔可以只寫喺側欄細字。

## 6. 渲染前自動檢查（全過先出草稿；另見 rhythm-variety.md 嘅機位、多樣性、動態檢查）
- 字級：所有可見文字 computed font-size ≥ 對應最細值
- 字幕：每組 ≤ 12 字、≥ 4 字（整句本身短除外）
- 禁區：文字方框同面部禁區零重疊

## 7. 特效字同字幕要一眼分得開（用戶回饋 2026-09-30，doctor2 草稿）
- **唔好喺字幕位出「似字幕」嘅特效字**：膠囊／色塊關鍵詞如果放喺字幕區（y 1330–1520）而字級又同字幕差唔多（72–90px），觀眾會以為字幕不斷轉款式。
- 特效字一定要同字幕有兩樣以上唔同：**位置**（放 headroom y 200–560 或者畫面側邊，唔放字幕區）、**大細**（≥ 字幕 1.6 倍即 ≥ 130px，或者係細標籤 ≤ 64px）、**形態**（圖形化：配 icon、線條、數字）。
- 特效字出現嗰句唔出字幕，但特效字唔好寫成成句說話，只寫關鍵詞。
- **閱讀負擔**：每個特效字元素 ≤ 8 個中文字；全屏卡標題只放關鍵詞（例如「3 個心臟問題」），唔好將旁白原句（「因為氣喘有機會可能是」）放上畫面；同一畫面同時要讀嘅字 ≤ 20 字。
- **名牌（FX-064）盡量喺片頭出**：第一句講嘢時（0.3–4 秒）出，停 2.5–3.5 秒；同 hook 大字一齊出就放唔同區（hook 喺頂，名牌喺胸口位 y 1050–1300），唔好擺到片尾。

## 9. 畫面字要「字對聲」（用戶回饋 2026-09-30，最重要）
- 每個特效字、標籤、title tag、卡片內容：**用字一定係醫生嗰刻講緊嘅字**（書面語校正後），唔准改寫（例如佢講「體能下降」就唔好寫「體能差」；講「便氣喘」就唔好寫「就喘」）。
- **出現時間 = 講出嗰個字嘅時間**（由逐字時間計，唔好人手估）；唔可以早過講出嚟。
- 字幕逐字跟轉錄；ASR 聽錯要改嘅字列明（例如「心臟代謝」其實係「新陳代謝」），唔好自己估新詞。
- 頂部大字全片最多 4 個，隔 ≥ 8 秒；其餘用字幕、側邊標籤、圖片。
- 交叉／劃線要同底字唔同色（字深藍、交叉紅），而且蓋住成個詞。
- 工具：`tools/qa.py check index.html chars.json`（字對聲、字數、數量、重疊、動畫 lint）+ `node scripts/qa-stills.cjs <專案> <frames> <out>`（逐個截圖、IG 安全區、logo、置中、文字有冇顯示、結束後有冇殘留）。兩樣都過先渲染。
