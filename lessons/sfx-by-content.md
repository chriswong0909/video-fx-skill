# 聲效要跟內容揀，唔好成條片幾款輪流用（用戶 2026-10-04，40S）

草稿 1 用咗 9 款通用聲（whoosh、pop、click），用戶話「太單一、冇因應內容」。

- **每個聲效先問：畫面／說話嗰刻係講緊乜？** 揀同內容有關嘅聲，節拍表「點解」一欄要寫明對住邊個字／邊個畫面。
  - 問題 → 疑問音（SFX-083–086）；「準確」／剔號／清單 → 確認音（SFX-033–036）；「錯」→ 錯誤音（SFX-041–048）
  - AI／電腦／報告畫面 → 電腦運作聲襯底（SFX-416–419，用 `dur` 截短，vol 約 0.06）、掃描下掃（SFX-378–380）、打字（SFX-007）
  - 課室／書 → 翻書（SFX-306–308）；寫字／練習 → 刮擦（SFX-087–091）；名牌／紙卡 → 紙卡滑動（SFX-260–267）
  - 「更加好」／進步 → 升級音（SFX-388–399）；洩氣／唔鍾意 → 低音下滑（SFX-365）、高音下滑（SFX-354）；「開解」→ 打開（SFX-077–080）
- 通用 whoosh／pop 只留喺純轉鏡頭；同一款全片最多 2 次。
- 揀聲之前睇晒 `sounds/INDEX.md` 成個庫（579 個），唔好只用頭 18 個自製聲。
- 音量：庫入面嘅聲全部峰值約 -1.5 dB，但平均響度差好遠。平均響度高（-10 至 -13 dB，例如疑問音、確認音、下滑音）用 vol 0.18–0.22；平均響度低（-27 dB 以下，例如翻書、紙卡、打字）用 0.45–0.7；襯底環境聲 0.06。
- `sfx.py mix` 嘅 cue 可以加 `dur`（秒）：長聲效只用頭幾秒，尾 0.4 秒淡出。
