# 設計原則（方向性；2026-10-22 高血壓篇歸納，取代之前零散嘅細規則）

具體做法每條片自己判斷，下面括號只係例子，唔係清單。

1. **比喻要忠於本體**：MG 用比喻（水管、水泵、樓宇…）時，形狀、結構、動作要符合真實事物，唔好畫出現實冇嘅嘢；比喻要畫比喻本身，唔好畫返原物。
   （例：血管係連續嘅，冇盡頭；「脊椎似一棟樓」就畫真正嘅樓，而且只係上半傾斜；心臟泵血要同血管連住。）
2. **畫面唔可以空、唔可以單調**：任何一刻都要有內容同動態；講者講到重點之前用引子填位，唔好得空底等。背景要有少少同主題相關嘅細節，唔好得一隻色；字唔好得一句擺喺畫面中間當字卡。
   （例：病徵未講前先放三張「?」卡；背景細節要跟每條片題材重新揀——心臟／血壓題材先用心電圖線，飲食題材用葉仔、種子、淡彩虹線，唔好沿用上一條片嘅背景；全屏效果第一個元素出現前空白唔超過 0.3 秒。）
3. **效果要有變化**：同一款效果唔好連續用；每條片嘅開場、結尾同重點場景唔好照搬上一條片；同一畫面唔好重複同一句字（標題、膠囊、字幕唔好寫同一樣嘢）。
   （例：印章一條片用一次；上條片用咗清單收尾，今條改 2×2 翻卡；揀效果先用未用過嘅。）
4. **主體一定要完整見到**：圖入面嘅主角同佢手上嘅嘢，唔可以俾字、標籤、裁切或者其他元素遮住。
   （例：圖卡標籤放圖下面，唔疊喺圖上；上圖下人裁圖要睇主體。）

## 自己 QA（技術）
- 交片前逐個 MG 用 `npx hyperframes snapshot` 截關鍵格睇：有冇元素唔見、遮擋、出界。
- 自訂 class 名唔好太短太通用（`.b1`、`.b2`）：同一個 composition 入面背景裝飾同內容撞名，`querySelector` 會揀錯元素，令內容唔顯示（2026-10-22 對話氣泡因此消失）。
