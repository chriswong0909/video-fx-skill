# 節奏、機位、開場、動態同多樣性

來源：doctor-stairs-breath（2026-09-29）用戶回饋：開場效果唔明顯、推鏡差距太少硬剪感強、0:26 長時間靜止、效果重複太多。

## 1. 機位（單機位口播，用 #cam wrapper 縮放模擬三個機位）
- 固定三個機位，唔好每鏡隨意揀倍數：
  - 闊鏡 W = 1.0（頭頂留空，頭頂特效字只可以喺闊鏡用）
  - 中鏡 M = 1.3
  - 特寫 C = 1.7（上限：原片 1080 闊，再大會模糊；原片解像度較高可按比例放寬）
- 推鏡中心固定喺眼睛高度（先偵測面部，眼睛約喺面部方框上 40%），所有機位眼睛高度一致；**唔好為避開文字逐鏡改推鏡中心**，改為揀啱機位。
- 每鏡內慢推 +3%（避免靜止）。

## 2. 切點
- 相連兩個醫生鏡頭嘅倍數差 ≥ 1.3 倍，唔可以連續用同一機位。
- 相連兩個硬切至少相隔 1.5 秒；任何一鏡最短 1.0 秒。
- 切喺停頓、換氣位（ASR 詞語之間 ≥ 0.15 秒嘅空隙），唔好切喺句中。
- 重點句用 FX-040 平滑推鏡（0.24 秒 ease）代替硬切；每 20 秒約 1 次，唔好濫用。

## 3. 開場（頭 3 秒）
- 開場字要喺 0.1 秒內出現，停留最少 2.5 秒，內容係成條片嘅問題或者結論（例如「行一層就喘？」），唔好係跟讀音嘅碎字。
- 開場大字最少 150px；頭頂位唔夠就放胸口位（闊鏡），期間唔出字幕。
- 唔好用只停留 0.5 秒嘅大字做開場。

## 4. 動態（唔准長時間靜止）
- 任何連續 1 秒以上，畫面相隔 0.5 秒嘅平均差異要 ≥ 0.6（135×240 灰階）。
- 常見靜止位同解決：
  - 全屏圖片、卡片、圖示：Ken Burns 慢推（6–14%）或者輕微浮動
  - 效果出齊之後嘅停留：文字或整組慢慢放大 5–8%
  - 講者縮細（講者卡、膠囊遮罩）：外框慢推或者上移
  - 清單類：元素輕微浮動
- 全屏效果唔好比讀音早開始太多：第一個元素出現前嘅空白背景唔好超過 0.3 秒（例如畫廊要等讀到第一項先開始，之前留返講者 + 字幕）。

## 5. 多樣性
- 同一效果每 60 秒最多 2 次，兩次相隔至少 15 秒（機位縮放、FX-039／FX-051 字幕、FX-040 平滑推鏡除外）。
- 同一類畫面（例如「頭頂一行大字」：FX-017、FX-037、FX-013）全片最多 3 次。
- 每 15 秒段落至少出現一個唔同類別嘅效果。
- 揀效果時先列出所有 fits 符合嘅效果，優先用未用過嘅，唔好因為易擺位就重複用同一個。
- 效果庫某類別（開場、轉場）冇可用效果時，要喺分鏡確認時講明，並建議用戶提供參考片補充。

## 6. 自動檢查（渲染後）
- 動態檢查：`motion.py <draft.mp4>`，列出所有 ≥ 1 秒嘅靜止段，要全部清零先出正式版。
- 機位檢查：相連醫生鏡頭倍數差 ≥ 1.3、硬切間距。
- 多樣性檢查：按分鏡嘅效果使用記錄計次數同間距。

```python
# motion.py（相隔 0.5 秒比較；門檻由實測校準：空白背景 0.0、用戶投訴嘅靜止段 0.49、講者講嘢 2.5）
import sys,subprocess,numpy as np
raw=subprocess.run(['ffmpeg','-v','error','-i',sys.argv[1],'-vf','scale=135:240,format=gray','-f','rawvideo','-'],capture_output=True).stdout
a=np.frombuffer(raw,np.uint8).reshape(-1,240,135).astype(np.int16); fps=15; lag=7   # 草稿 15fps
d=np.abs(a[lag:]-a[:-lag]).mean(axis=(1,2)); still=d<0.6; runs=[]; s=None
for i,v in enumerate(list(still)+[False]):
    if v and s is None: s=i
    if not v and s is not None:
        if (i-s)/fps>=1.0: runs.append((round(s/fps,1),round(i/fps,1)))
        s=None
print(runs)
```
