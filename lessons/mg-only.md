# 純 MG 素材（模式 E）實戰教訓

來源：漱口水篇（2026-10-10–14）、超級食物篇（2026-10-20–21）。規則摘要喺 `skills/video-fx/SKILL.md` 第 10 節；呢度記低點解。

## 用戶否決過嘅做法
| 做法 | 用戶反應 | 改成 |
|---|---|---|
| 第一版：簡單圖形、動作少 | 「效果太簡單，畫面不夠豐富，節奏太慢」 | 加背景層、細節同動作 |
| 每 0.6 秒換一個拍子，加斜向 wipe、速度線 | 「太快，睇唔切」 | 一句 VO 一個主畫面 |
| 成段拉慢 20%（畫面遲過 VO） | 「仍然太快」，改返第一版節奏 | 減拍子數，唔好慢放 |
| 每段加標題、步驟點、步驟卡、進度條（模仿 prompt-motion Negroni） | 「唔想你強行每次加條類似 timeline 既嘢」 | 只喺需要時加 |
| 頂部 super 寫返 VO 句子 | 「同字幕資訊重覆」 | 預設唔加，靠畫面元素交代 |
| 沿用上條片嘅水泡背景 | 「與主題完全無關」 | 每段按內容配淡紋理 |
| 生果疊喺籃前面／後面 | 「放入籃後在圖片後面」 | 容器分前後兩層 clip-path |
| 頂部 super 同印章同字 | 「真正平靚正出現咗兩次」 | 同一字唔出兩次 |
| 成對 price tag 長短唔同 | 「底應該一樣長」 | 固定闊度、字置中 |
| 「＝」被菜籃遮 | 指出 | 符號放最上層 |
| 冇就到出血位、super 畚字幕遮 | 指出要守安全區 | 字 212–1340、左右 52、留 logo 位 |
| 全部手畫 SVG 食物 | 建議用 Canva 生圖配 MG | 實物用 Canva 生圖、MG 負責郁 |

## Canva 落圖坑
- `get-generate-image-job`／`get-assets` 只俾 200px 縮圖；簽名 URL 改尺寸會 403。
- 正確路線：`separate-image-layers`（等 job 完成）→ `export-design` PNG → curl 下載（1264px）。
- 去背：本機 `rembg` isnet-general-use（模型由 GitHub releases 下載，雲端得）。
- 一張圖兩件物件（椰子兩半）：後面嗰件內部會被去走變透明 → 只裁用一件，或者生成單件。
- prompt 尾綴：`isolated on a pure white background, high-end product photography, soft studio lighting, soft shadow, ultra sharp, no text`；包裝類加 `completely blank, no printing, no logos`。

## 容器分層做法
1. 喺原圖疊 50px 格線，睇清楚開口前沿條曲線。
2. 前沿層：同一張圖，用 `clip-path: polygon(...)` 只保留前沿以下部分（籃：0% 54% → 50% 71.5% → 100% 54% → 底；木箱：0% 21%, 83% 41%, 99.5% 17%, 底）。
3. 次序：容器全圖 → 物件 → 前沿層。物件落點對準開口，落地加小彈跳。

## 驗收
- 每段抽 2–4 格，疊安全框（紅：212–1556 / 52–1028；黃：字幕 1380–1556；藍：logo 742–1020 × 228–360）自己睇過先交。
- 聲效聽唔到，交片要請用戶試聽。
